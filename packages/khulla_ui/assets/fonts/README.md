# Fonts

**Lexend** — <https://fonts.google.com/specimen/Lexend>, licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org).

Lexend is designed to reduce visual stress and improve reading proficiency,
which makes it a deliberate choice for a library product rather than a
stylistic one.

Before the first public release, drop the upstream `OFL.txt` from the
[Lexend repository](https://github.com/googlefonts/lexend) into this folder —
the OFL requires the licence text to ship alongside the font files.
